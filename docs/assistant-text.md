# POST /api/assistant/text — ввод и обработка команды

Зависимость — [PostgreSQL и демо-данные](./foundation.md). Голос вызывает тот же серверный обработчик после финальной транскрипции.

## Контракт

Передавайте `Content-Type: application/json` и `X-Zoya-Contract: nuxt`. Примеры ниже также соответствуют полю `data` события `result` в WebSocket.

Вход — `{"text":"Закажи молоко 3,2%, творог и десяток яиц на субботу утром"}`. Принимаем от 1 до 1000 символов после обрезки пробелов. Пустой или некорректный запрос возвращает `400 INVALID_REQUEST`, сбой классификации — `503 ASSISTANT_UNAVAILABLE`.

### `farmer-products`

```json
{
  "intent": "farmer-products",
  "recognizedText": "Закажи молоко 3,2%, творог и десяток яиц на субботу утром",
  "payload": {
    "items": [
      {"id": 1, "name": "Молоко 3,2%", "unitLabel": "1 л", "qty": 1, "price": 129, "imageUrl": "/static/products/1.webp"},
      {"id": 2, "name": "Творог 5%", "unitLabel": "400 г", "qty": 1, "price": 219, "imageUrl": "/static/products/2.webp"},
      {"id": 3, "name": "Яйца С0", "unitLabel": "10 шт", "qty": 1, "price": 149, "imageUrl": "/static/products/3.webp"}
    ],
    "totalPrice": 497,
    "unmatchedItems": [],
    "delivery": {"date": "2026-11-21", "slot": "09:00-12:00", "address": "ул. Красная, 122"},
    "deliveryIssue": null
  }
}
```

`unmatchedItems` — массив названий запрошенных позиций, которые нельзя подобрать с нужными характеристиками или количеством. При неподдерживаемой дате или времени сервер возвращает `delivery: null` и `deliveryIssue: "UNSUPPORTED_DELIVERY"`. Nuxt показывает причину и даёт исправить команду. При пустой корзине, неполном подборе или отсутствии слота подтверждение недоступно.

### `analytics`

```json
{
  "intent": "analytics",
  "recognizedText": "Куда я тратила больше всего в этом месяце?",
  "payload": {
    "period": "2026-11",
    "totalSpent": 87500,
    "categories": [
      {"code": "cafes", "name": "Кафе и рестораны", "amount": 42000, "percent": 48},
      {"code": "groceries", "name": "Супермаркеты", "amount": 23625, "percent": 27},
      {"code": "transport", "name": "Транспорт", "amount": 14000, "percent": 16},
      {"code": "pharmacies", "name": "Аптеки", "amount": 7875, "percent": 9}
    ],
    "aiAdvice": "Больше всего за месяц ушло на кафе и рестораны. Можно отложить часть свободных средств на вклад под 14% годовых.",
    "depositOffer": {"currency": "RUB", "rate": 14, "termMonths": 6, "minAmount": 500, "maxAmount": 10000000, "defaultAmount": 800000, "accountBalance": 1800000}
  }
}
```

### `deposit`

```json
{
  "intent": "deposit",
  "recognizedText": "Открой вклад на двести тысяч рублей",
  "payload": {
    "requestedAmount": 200000,
    "depositOffer": {"currency": "RUB", "rate": 14, "termMonths": 6, "minAmount": 500, "maxAmount": 10000000, "defaultAmount": 800000, "accountBalance": 1800000}
  }
}
```

`requestedAmount` — сумма из команды в рублях или `null`, если её не указали. Калькулятор берёт `requestedAmount ?? depositOffer.defaultAmount` и включает подтверждение для целой суммы в пределах лимитов продукта и текущего баланса. Пользователь может исправить недоступную сумму. Обработка команды только готовит предложение. Вклад открывается после явного подтверждения через [`POST /api/actions/deposit`](./actions-deposit.md).

Текстовый запрос без `X-Zoya-Contract: nuxt` и загрузка аудио по HTTP дополнительно возвращают `"status": "success"`.

### `unknown`

```json
{
  "intent": "unknown",
  "recognizedText": "Оплати ЖКХ",
  "message": "Могу собрать заказ фермерских продуктов, показать траты за месяц или помочь открыть вклад."
}
```

## NestJS

- Использовать YandexGPT Lite для определения интента и извлечения полей, валидировать структурированный ответ. Для заказа извлекать товар, характеристики, количество, единицу, дату и время доставки. Для вклада извлекать сумму в рублях. Невалидный ответ провайдера обрабатывать как ошибку классификации.
- Подбирать позиции из PostgreSQL по имени и характеристикам. Если пользователь не назвал товары, отдавать три демо-позиции. Для «десятка яиц» возвращать одну упаковку по 10 шт. Сервер определяет итоговую цену и переводит относительные даты в календарные даты по времени Москвы. При отсутствии даты использовать ближайший доступный утренний слот.
- Для аналитики собрать траты за текущий календарный месяц, отсортировать категории по сумме и округлить доли до целых процентов. При отсутствии трат вернуть ноль и пустой список. Передать модели агрегаты для короткого совета, при сбое генерации совета использовать текстовый шаблон. Ставку и условия брать из общей конфигурации вклада. Начальная сумма — 800 000 ₽ в пределах доступного остатка, либо `null`, если остаток ниже минимума. Записать успешный результат аналитики в историю один раз на обработанную команду.

[Справочник YandexGPT Text Generation API](https://aistudio.yandex.ru/ru/docs/ai-studio/text-generation/api-ref/TextGeneration/completion)

## Nuxt

- Текстовое поле и подсказки отправляют команду через этот эндпоинт. Для `farmer-products` показать распознанную команду и детали, по кнопке открыть внутренний маршрут с черновиком корзины.
- Для `analytics` показать диаграмму и предложение вклада с переходом в калькулятор. При пустом месяце показать пустое состояние. Для `deposit` сразу открыть калькулятор. Для `unknown` показать доступные подсказки и дать отправить новую команду.

## Приёмка

- Текст и финальная голосовая транскрипция проходят один обработчик и дают одинаковые поля ответа.
- Для демо-фразы корзина содержит три позиции на 497 ₽, яйца идут одной упаковкой. Неизвестный товар отображается в списке неподобранных.
- Суммы диаграммы совпадают с БД и итогом за месяц. Неподдерживаемая команда возвращает `200` с `unknown`, а недоступность классификатора даёт ошибку.
