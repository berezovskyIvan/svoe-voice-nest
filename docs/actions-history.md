# GET /api/actions/history — меню и история

Зависимость — [общие таблицы и демо-данные](./foundation.md). Эндпоинт можно подключать на сиде до выполнения задач заказа и вклада.

## Контракт

Передавайте `X-Zoya-Contract: nuxt`, чтобы получить поле `user` и типы истории из примера.

```json
{
  "user": {"name": "Екатерина"},
  "balance": 1799503,
  "history": [
    {"id": 6, "type": "order", "title": "Заказ фермерских продуктов", "subtitle": "Молоко 3,2%, Творог 5%, Яйца С0", "amount": 497, "createdAt": "2026-11-20T08:40:00.000Z"},
    {"id": 5, "type": "analytics", "title": "Куда я тратила больше всего?", "subtitle": "Кафе и рестораны · 48%", "amount": null, "createdAt": "2026-11-20T08:32:00.000Z"},
    {"id": 4, "type": "demo", "title": "Оплата ЖКХ за октябрь", "subtitle": "Оплачено", "amount": 6420, "createdAt": "2026-11-19T07:30:00.000Z"}
  ]
}
```

Типы записей — `order`, `analytics`, `deposit`, `demo`. Интенты помощника описаны отдельно. Сортировка по `createdAt DESC, id DESC`. Пустая история возвращается как `history: []`.

## NestJS

- Вернуть имя и текущий баланс демо-пользователя и историю. Читать согласованный снимок счёта и истории, чтобы списание совпадало с лентой. Скрыть внутренние поля идемпотентности и снимки операций из ответа списка.
- Добавлять запись аналитики после успешной обработки команды, заказ и вклад — при подтверждении, с тем же коммитом, что и списание средств. Сидовые ЖКХ и другие записи для демонстрации помечать как `demo`.

## Nuxt

- Загружать данные для приветствия и меню, обновлять историю после успешной аналитики, заказа и вклада. Форматировать время и сумму. При ошибке загрузки показывать возможность повторить запрос.
- «Новый разговор» возвращает к вводу и очищает текущий экран на клиенте. Для ленты достаточно кратких строк. Чипы, требующие отдельного сценария, скрыть или сделать недоступными.

## Приёмка

- После команды аналитики в ленте есть её результат, после подтверждения заказа или вклада — запись операции и обновлённый баланс.
- Просмотр меню и повторная загрузка ленты не создают записей. Отменённые операции и неподдерживаемые команды в ленту не попадают.
