# POST /api/actions/deposit — подтверждение вклада

Зависимости — [предложение из аналитики](./assistant-text.md), [демо-счёт](./foundation.md).

## Контракт

Вход — `{"amount":800000}`. Заголовок `Idempotency-Key` — UUID подтверждения. Валюта, срок, ставка и счёт задаются сервером. Условия MVP для реализации — RUB, 6 месяцев, 14% годовых, один счёт, без капитализации, пополнения и частичного снятия. Диапазон — от 500 до 10 000 000 ₽ включительно в пределах текущего баланса.

```json
{
  "depositId": 7,
  "amount": 800000,
  "currency": "RUB",
  "rate": 14,
  "termMonths": 6,
  "estimatedInterest": 56000,
  "estimatedTotal": 856000,
  "newBalance": 999503
}
```

Для MVP `depositId` — идентификатор записи вклада в истории. Пример баланса предполагает, что перед вкладом с исходного счёта уже списали 497 ₽ за заказ. Для демо расчёт простых процентов — `round(amount × rate × termMonths / 1200)` с округлением до ближайшего рубля, половина рубля округляется вверх. `estimatedTotal` — внесённая сумма плюс доход за срок. Для 800 000 ₽ по этому правилу доход **56 000 ₽**. Использовать те же цифры в предложении, калькуляторе и на экране подтверждения.

| HTTP | Код | Когда возвращается |
| --- | --- | --- |
| 400 | `INVALID_REQUEST` | Некорректная сумма, сумма вне диапазона, лишние поля или отсутствует ключ |
| 409 | `INSUFFICIENT_FUNDS` | Сумма превышает актуальный баланс |
| 409 | `IDEMPOTENCY_CONFLICT` | Повторное использование ключа с другим запросом |

## NestJS

- Описать условия продукта в общей конфигурации для аналитики и открытия вклада. Проверять сумму и баланс на сервере, считать доход по формуле выше.
- В одной транзакции PostgreSQL заблокировать строку счёта, проверить повтор подтверждения, списать сумму и сохранить снимок условий и результат операции в истории. Повтор с тем же ключом и суммой возвращает сохранённый ответ.

## Nuxt

- Из аналитики открыть калькулятор и заполнить начальную сумму. При редактировании локально считать доход по правилам контракта. Показать фиксированные условия и баланс. Если баланс ниже минимума, показать предложение с недоступным подтверждением.
- Дать проверить параметры перед кнопкой «Открыть». Заблокировать кнопку на время запроса и сохранять ключ при сетевом повторе. После успеха показать результат и обновить историю.

## Приёмка

- Для 800 000 ₽ калькулятор и сервер показывают один доход и одни условия.
- Вклад открывается только после явного подтверждения. Двойной запрос даёт одну запись и одно списание.
- Если остаток изменился после показа предложения, сервер применяет актуальный баланс. При недостатке средств история и баланс сохраняются.
